Python「==」と「is」の違い

出典画像: differenceOfEcalAndIs.jpeg

4 項目

画像の主旨は「== は値の等価性、is は同一オブジェクトかを判定」。文字列の is の結果は実装・最適化に依存し得るため、値比較には == を使うのが基本です。

ケースセットアップ==is
基本== は値、is はオブジェクト同一性を判定値が同じか同じオブジェクトか
Mutable：別々のlistlist1=[3,4,5]; list2=[3,4,5]True（同じ値）False（objが異なる）
Mutable：同じlistを参照list1=[3,4,5]; list2=list1True（同じ値）True（objも同じ）
Immutable：文字列str1="Car"; str2="Car"True（同じ値）True（画像例では同じobjを参照）

yt-dlp：動画サイトからDownload

出典画像: download_byYoutube.jpeg

9 項目
項目内容コード / 備考
yt-dlpとは動画サイトから好きな動画をダウンロードするライブラリyoutube-dlライブラリの後継版
特徴コマンド実行のほかPythonからも利用可能youtube-dlより高速とされる
FFmpeg併用すると音声抽出などが便利FFmpegを別途導入
部分DLサムネイルや動画の一部を切り抜いてダウンロードすることも可能オプションで指定
インストールyt-dlpを導入pip install yt-dlp
インポートYoutubeDLを読み込むfrom yt_dlp import YoutubeDL
mp4指定フォーマットをmp4に指定yt_opts = YoutubeDL({'format': 'mp4'})
ダウンロード指定パスの動画を取得yt_opts.download('動画のパス')
注意違法ダウンロードや著作権侵害など、法に触れないよう注意利用権限を確認

pathlibでパスを取得

出典画像: getpath.jpeg

6 項目
項目内容コード
pathlibとはファイルやフォルダのパスを扱うライブラリosやglobでも同様の処理が可能
目的フォルダ内の特定拡張子ファイルの絶対パスをリストで取得例：Excelファイルだけ抽出
インポートpathlibを読み込むimport pathlib
フォルダ指定検索対象フォルダpath_dir = r"C:\test"
拡張子指定* は任意の文字列ext_file = r"*.xlsx"
一覧取得glob結果をlist化list_path = list(pathlib.Path(path_dir).glob(ext_file))

icrawler：ネット画像の自動収集

出典画像: icrawler.jpeg

6 項目
項目内容コード / 例
icrawlerとは検索エンジン等から画像を自動収集できるライブラリGoogle / Baidu / Bing / Flickr
指定方法Webサイト指定や画像URL指定も可能icrawler
インストールicrawlerを導入pip install icrawler
インポートGoogleImageCrawlerを読み込むfrom icrawler.builtin import GoogleImageCrawler
保存先root_dirに保存先フォルダを指定crawler = GoogleImageCrawler(storage={"root_dir": "dogs"})
収集例：Googleから「犬」の画像を100枚収集crawler.crawl(keyword="犬", max_num=100)
