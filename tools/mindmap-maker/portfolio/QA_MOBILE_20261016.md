# MindMap Maker v1.1 iPhone操作改善 QA

Date: 2026-10-16
Branch: `fix/mindmap-iphone-touch-ux-20261016`

## 改修対象

- 操作イベントをSVGノードとキャンバスの二重管理から、キャンバスでのタッチ一元管理へ変更
- タップとドラッグのしきい値（9px）を設定し、空白タップでの追加・空白ドラッグでのパンを明確に区別
- ノード上で始めても2本指ピンチが成立するように変更し、前後の座標を中点基準で補正
- ノード選択後の編集/接続/スタイル/その他を下部へ配置
- 形状パネルを追加モードだけに表示し、他モードの編集キャンバスを拡張
- セーフエリア/小画面ダイアログのスクロールへ対応。iPhone横画面もモバイル操作バーを表示
- JSONファイル形式 version 5 / localStorage key `mindmap-maker-v3` / PCのクリック・ドラッグは変更なし
