COMPOSITION PIPELINE

曲ができるまで

  1. 01Seed

    同じSeedなら同じ曲を再現できる状態から開始。

  2. 02Compose

    モチーフ、A/B/Chorus、調性、和音、リズム文法からMIDIを構成。

  3. 03Evaluate

    複数候補を自動評価し、人間が最終候補を選択。

  4. 04Synth

    Python自作SynthでBass / Chords / Drums / Melodyを実音源化。

  5. 05Mix & FX

    Filter、Delay、Reverb、Track Mix、normalizationを適用。

  6. 06Export

    WAV / OGG / 静的JSONとして書き出し、Webでも再生可能に。

PROJECT BOUNDARY

完成系統と研究中の系統を分ける

完成済み: Non-Generative Composer v1.0。生成AIなしで、ルール作曲からMIDI、自作Synth、実音源まで独立して動作します。

研究中: 別経路として生成AIレンダリング連携も検証中です。既存の作曲ロジックを置き換えず、演奏・音色・アレンジ候補を追加する研究として分離しています。
