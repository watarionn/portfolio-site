# よふかしおばけ町

iPhone向けに作った、オフライン対応の箱庭育成＋3個連結パズル。独立作品であり、Godot製「Ghost Home Game」のコードやゲーム仕様を変更しない。

## 遊びかた

- 5×5 の空き地に、次の建物を置く。上下左右につながった同じ種類が3つ以上になると、置いた場所でひとつ上の種類に進化する。連鎖あり。
- 進化で評判（得点）と月のおこづかいを獲得。おこづかいは１手もどす（6）、おそうじ（12）、引きなおし（4）に使う。
- 建物9種類、発見図鑑、6実績、累計記録、通常モード／日付シード固定のデイリーモード。記録は端末のlocalStorageに保存される。
- 音は初期オフ。通信なしで進行する。サーバ、ログイン、外部CDN、追加ライブラリ不要。

## ローカルで試す

`python -m http.server 8000` を`public/` ディレクトリで実行し、`http://localhost:8000/` にアクセスする。

## iPhoneでホーム画面へ追加

HTTPS上の独立したパスにファイル一式を置く。iOSのSafariでページを開き、共有メニューの「ホーム画面に追加」を選ぶ。`file://` やZIPを開くだけではservice workerが使えないため、オフラインPWAのインストールはできない。サービスワーカーのscopeは配置したディレクトリのみに制限。

## プライバシーとデプロイ

データはブラウザ内にだけ保存される。既存サイト／Rinka Lab／Ghost Home Gameの正本や本番ファイルを自動変更しない。公開する場合はそのプロジェクトの承認・レビュー・デプロイルールに従う。

## ファイル

- `index.html`: UI
- `style.css`: 画面表示
- `game.js`: ゲームルール・保存処理
- `sw.js`: オフラインキャッシュ
- `manifest.webmanifest`: PWA設定
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`: アイコン
