# ControlNet Pose Helper

SDXL / ControlNet向けのポーズ参照画像を作るための、HTML/CSS/JSだけで動く簡易ツールです。

## 使い方

1. `index.html` をブラウザで開く。
2. プリセットを選び、関節をドラッグしてポーズを調整する。
3. 必要なら参照画像を読み込み、下絵として使う。
4. `PNG保存` でControlNet用画像として保存する。
5. 後で再編集したい場合は `JSON保存` も行う。

## 出力モード

- OpenPose風カラーマップ: OpenPose ControlNetへ直接渡す条件画像向け。
- 黒線の棒人間: Cannyや構図確認向け。
- 白線の棒人間: 黒背景で見やすい棒人間画像向け。
- 簡易シルエット: DepthやCannyの下絵として、人体の塊を見せたい場合向け。

## 注意

このツールは2D棒人間ベースです。厳密な3D素体、カメラ回転、手指、顔向き、服の布変形などは扱いません。
人物の同一性はControlNetではなく、プロンプト、LoRA、IP-Adapterなどで制御してください。

## ファイル構成

- `index.html`: 画面構成
- `style.css`: 見た目
- `app.js`: ポーズ編集・保存処理
