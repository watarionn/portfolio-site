01 / BLUEPRINT ENGINE

直径を決める。
断面で積む。
立体で確かめる。

奇数サイズの立方グリッドへ球体を量子化し、建築に使える一段ごとの配置へ分解します。まず中央断面を見て、必要なら3Dで全体像を確認してください。

02 / LOGIC

距離を測る。
マスを残す。
断面へ切る。

立方グリッドの中心から各マスまでの距離を求め、半径の内側に入るマスだけを球体として採用します。空洞モードでは、さらに内側の球を差し引いて外殻だけを残します。

計算結果は同じボクセル集合から2D断面と3Dプレビューを作るため、見せ方を切り替えても設計データそのものは変わりません。

03 / BUILD FLOW

球体から、
建築手順まで。

  1. 01SIZE

    直径に相当する奇数グリッドを決め、中心座標と半径を確定。

  2. 02VOXELIZE

    中心からの距離で各マスを判定し、球体をブロック集合へ変換。

  3. 03SLICE

    高さまたは奥行きで切り出し、1段ずつ追える平面設計図を生成。

  4. 04PREVIEW

    外周面だけをCanvasへ投影し、軽量な3D確認ビューとして描画。

04 / DETAILS

建てるときに、
迷う場所を減らす。

01

中央から始める

再計算時は中央断面へ戻り、球体の最大径を最初に確認できます。

02

断面を直接移動

前後ボタンだけでなくレイヤースライダーを使い、離れた段へすぐ移動できます。

03

3Dは外周だけ描く

中実球でも内部ブロックを描画対象から外し、見た目を保ちながらCanvas負荷を抑えます。
