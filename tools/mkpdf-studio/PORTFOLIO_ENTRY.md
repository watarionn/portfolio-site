# Portfolio Entry

## Title

mkPDF Studio

## Building name

製本工房

## Type

Python / Desktop / PDF

## Summary

画像入りアーカイブを展開前に安全検査し、ページの並べ替え・回転・除外を確認してからPDFへまとめるローカルファーストのWindowsデスクトップツール。

## Key points

- ZIP / CBZ / 7z / RAR / CBR / CB7に対応
- 危険な展開パスやリンクを事前検査
- 原本アーカイブを削除しない設計
- ページプレビューと複数選択編集
- Undo / Redo
- PDF品質・A4プリセット
- 完成PDFのページ数まで検証
- 外部アップロード不要

## Portfolio positioning

既存の個人用mkPDFを、データ損失を避けるSafe Coreから再設計した作品。単なるアーカイブ一括PDF化ではなく、変換前の検査、ページ編集、完成検証までを1つのデスクトップUIで扱う。
