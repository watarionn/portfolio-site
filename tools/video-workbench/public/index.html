BROWSER LAB · LOCAL-FIRST

ブラウザで動画を切り出す

動画を外部へ送信せず、開始・終了位置をプレビューしながら指定して、その範囲をWebMとして書き出せます。ブラウザが再生・記録できる形式を利用します。

NEW

動画を結合

複数の動画を順番に並べ、ひとつのWebMへ録画します。各クリップはブラウザ内だけで処理されます。

    このツールについて

    Windowsデスクトップ版に加えて、Notebookで使っていた動画トリミング処理をブラウザから扱える形へ拡張しています。デスクトップ版は動画情報の確認、指定範囲の切り出し、PNG / JPGのフレーム書き出しを同じ画面から操作できます。

    Fast / Precise Cut

    ストリームコピーによる高速カットと、時間位置を優先する再エンコード方式を分けて選択できます。

    Frame export

    PNG / JPG、全フレームまたはFPS指定に対応。実行前におおよその出力枚数も確認できます。

    Media inspection

    ffprobeから動画の長さ、解像度、FPS、映像・音声ストリーム、ファイルサイズを取得して表示します。

    Local workflow

    動画は外部サービスへ送信せず、PC上のFFmpeg / ffprobeを使ってローカルで処理します。

    安全設計

    • 既存ファイル・既存出力フォルダへの上書きは既定で拒否
    • 開始・終了時間、FPS、JPG品質を実行前に検証
    • FFmpegを非対話モードで実行し、入力待ちによる停止を防止
    • 出力後にffprobeまたは生成フレーム数で結果を確認
    • 日本語や空白を含むWindowsパスに対応
