ControlNet Pose Helper

SDXL / ControlNet用のポーズ参照画像を作る簡易ツール。ドラッグで関節を動かし、PNG / SVG / JSONとして保存できます。

関節をドラッグしてポーズを編集
ホイール: 拡大縮小 / ドラッグ: 関節移動 / 矢印キー: 選択関節を微調整

大: ユーザーが主に触る設定

OpenPose ControlNetへ直接渡すなら「OpenPose風カラーマップ」、Canny用なら「黒線の棒人間」が扱いやすいです。

大: 保存

JSONは後で同じポーズを再編集するための保存形式です。PNGだけで作業を続けるという苦行を避けられます。

中: 編集補助

中: 下絵・トレース

小: JSON読み込み

保存済みJSONを読むと、キャンバスサイズ・関節位置・表示設定を復元します。

小: 選択関節

未選択

小: 使い方

  1. プリセットを選んで適用します。
  2. 関節をドラッグして目的ポーズに寄せます。
  3. 必要なら下絵を読み込み、上から関節を合わせます。
  4. PNG保存してControlNet参照画像に使います。
