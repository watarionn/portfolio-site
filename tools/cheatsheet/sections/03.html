出典画像: Emotion.jpg

8 項目
項目内容コード / 例
ライブラリFace Emotion Recognizer (FER)。怒り・嫌悪・恐怖・幸福・悲しみ・驚き・通常を推定pip install fer
インポートFERとOpenCVを読み込むfrom fer import FER import cv2
画像読込OpenCVで対象画像を読み込むimg = cv2.imread("***.jpg")
検出器作成FERの検出器を作成detector = FER()
感情推定画像から顔を検出し、7感情の強弱を返すdetector.detect_emotions(img)
出力パラメータangry / disgust / fear / happy / sad / surprise / neutral各感情を0〜1程度の強さで表現
画像例1happy が最も高い例happy 0.79 / neutral 0.16
画像例2disgust が最も高い例disgust 0.78
