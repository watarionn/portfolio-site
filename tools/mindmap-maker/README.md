# MindMap Maker v1.0.0

思考を、軽く、自由につなぐ。ブラウザだけで動く、SVGベースの軽量マインドマップエディタです。

サーバー、アカウント、ビルド工程、外部JavaScriptライブラリを必要とせず、PC・スマホの両方で利用できます。編集データはブラウザ内へ自動保存され、JSONでバックアップ・移行できます。

## 主な機能

- ノード追加・移動・複数選択
- 長方形 / 円 / 雲 / 菱形 / 三角形 / 矢印形状
- 曲線 / 直線の接続
- テキスト・色・枠線・文字サイズ編集
- グループ化
- Undo / Redo（最大60履歴）
- マップ名の設定
- ブラウザへの自動保存 / 手動保存 / 復元
- ノード全文検索と該当ノードへのフォーカス
- 接続関係を基準にした自動整列
- マップ全体表示
- ミニマップによる全体位置の把握・移動
- JSON保存 / 読み込み
- PNG / JPG / SVG出力
- 出力時は現在の画面範囲ではなくマップ全体を自動計算
- マウス・タッチ・ピンチズーム対応
- 初回オンボーディング / サンプルマップ / 操作ヘルプ

## すぐ試す

`index.html` をブラウザで開くか、任意の静的Webサーバーでこのディレクトリを配信してください。

初回起動時にガイドが表示されます。「サンプルを見る」を選ぶと、ノード・接続・グループ・複数形状を含んだデモマップをすぐ試せます。

サンプルJSONは `samples/product-launch.json` にも同梱しています。

## ショートカット

- `Ctrl/Cmd + Z`: 元に戻す
- `Ctrl/Cmd + Shift + Z` / `Ctrl/Cmd + Y`: やり直す
- `Ctrl/Cmd + S`: ブラウザに保存
- `Ctrl/Cmd + O`: JSONを開く
- `Ctrl/Cmd + F`: ノードを検索
- `Ctrl/Cmd + D`: 選択ノードを複製
- `Delete` / `Backspace`: 選択対象を削除
- `F`: マップ全体を表示
- `L`: 自動整列
- `?`: 操作ヘルプ
- `Esc`: メニュー / モーダルを閉じる

## 保存方式

編集内容は `localStorage` に自動保存されます。ヘッダーに「未保存 / 保存中 / 保存済み / 保存失敗」を表示します。

JSONにはノード、接続、グループ、マップ名、表示位置を保存します。v1.0では保存時のビューポートサイズも記録し、PCとスマホのように画面幅が大きく変わった場合はマップ全体が見えるよう表示位置を補正します。旧形式のJSONも不足項目を補完して読み込みます。

詳しいデータ取り扱いは `PRIVACY.md` を参照してください。

## 出力

PNG / JPG / SVG / JSONに対応しています。ファイル名にはマップ名を利用します。画像・SVG出力時はノード全体の外接領域から出力範囲を計算するため、画面外のノードも含まれます。
