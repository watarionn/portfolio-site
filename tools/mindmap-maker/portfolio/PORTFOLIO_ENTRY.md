# MindMap Maker

## Short copy

思考を、軽く、自由につなぐ。ブラウザだけで完結するSVGマインドマップエディタ。

## Description

MindMap Maker は、インストールやアカウント作成なしで使えるローカルファーストのマインドマップエディタです。SVGを描画基盤に採用し、ノード追加・接続・スタイル編集・グループ化・検索・自動整列・ミニマップ・Undo/Redo・JSON保存・画像出力を1つの静的Webアプリにまとめました。

元は個人用の小さなHTMLツールでしたが、既存機能を壊さずに、JSON再読込、キャンバス全体の画像出力、自動保存、検索、接続関係ベースの自動整列、ミニマップ、初回ガイド、アクセシビリティ対応を段階的に追加し、公開可能なv1.0へ仕上げています。

## Highlights

- Vanilla JavaScript / SVG / CSSのみ。ビルド工程・外部ライブラリなし
- ローカルファースト。編集データはブラウザ内に保存
- マウス・タッチ・ピンチズーム対応
- JSONで編集状態を完全保存・復元
- PNG / JPG / SVGでは、表示中の画面ではなくマップ全体を自動計算して出力
- ノード全文検索、ミニマップ、自動整列
- PC / Mobile両対応
- 初回ガイド、キーボード操作、Reduced Motion、フォーカス表示など公開品質を整備
