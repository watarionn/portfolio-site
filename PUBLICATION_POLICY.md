# Publication policy

This repository is a clean public portfolio export from the private production source repository.

## Stage 1 scope

Stage 1 intentionally contains only the reviewed portfolio shell, profile, static tools, and static works selected by the private export contract. Runtime-backed applications, server configuration, operator workflows, mutable state, private notes, and private Git history are out of scope.

Characters are intentionally excluded from this public portfolio export. YOREI, AQUARIUM, HOLOCA, HoloScope, SHISHA, and SECRET remain deferred until each receives a separate public-export review.

## Production boundary

This public repository is not the production authority. Production deployment, server credentials, protected runtime configuration, mutable state, and maintenance/operator workflows remain private and must not be added here.
