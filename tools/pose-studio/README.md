# Pose Studio 1.1.0

Pose Studioは、3Dマネキンと2D骨格を行き来しながらポーズを作り、ControlNet向けの画像・JSONとして書き出し、ポーズDBへ保存できる制作ツール。

## 3Dポーズ

アップロード版3DPoseCreatorの長所を引き継いでいる。

- 無個性のグレーマネキン
- 関節マーカーを指で直接ドラッグ
- 手首・ひじ・足首・膝などは簡易IKで追従し、腕・脚の長さを保持
- X / Y / Z角度編集
- カメラ回転・ズーム
- 基本ポーズプリセット
- 正面 / 右 / 背面 / 左の視点
- 透明PNG
- 4方向シート / 個別保存
- OpenPose画像 / JSON
- A ↔ Bアニメーション
- GIF / 動画出力
- 3DポーズJSON

## 2Dポーズ

既存ControlNet Pose Helperの長所を引き継いでいる。

- OpenPose COCO18相当の関節
- 関節ドラッグ
- 左右対称編集
- 「骨の長さを固定」を初期ON。ひじ・膝・手首・足首を動かしても四肢の長さを保持
- 下絵トレース
- グリッド / 関節名 / 椅子ガイド
- OpenPose風 / 棒人間 / シルエット
- PNG / SVG / OpenPose JSON
- 2DポーズJSON

## 3D → 2D

「現在視点を2Dへ送る」で、3Dマネキンの現在のカメラ視点をCOCO18相当の2D関節へ投影する。

3Dで大きな姿勢を決め、2DでControlNet向けに関節位置を詰める流れを想定する。

## ポーズDB

3D・2Dのどちらからでも同じDBへ保存する。

3Dから保存した場合は、

- 3D関節角度
- ルート高さ
- カメラ位置
- 現在視点から投影した2D骨格
- タイトル / タグ

を一緒に保存する。

2Dから保存した場合は2D骨格と表示設定を保存する。

ブラウザ内DBは作業用で、長期保存時は `pose-db.json` を書き出してGitHub / Google Drive側へ保存する。

## 安全な素体方針

3D素体は人物性を持たないグレーマネキンに固定する。

ポーズから参照するのは姿勢・関節角度・接触関係・構図であり、顔・髪・年齢・体型・人物同一性は引き継がない。

## 内部構成

- `pose3d.js`: 3D編集、投影、出力、アニメーション
- `pose2d.js`: 2D編集、トレース、OpenPose出力
- `store.js`: ポーズDB
- `app.js`: 画面切替、DB連携、ヘルプ
- `gif.js`: ローカルGIFエンコーダ
