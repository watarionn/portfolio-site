Asynchronous JavaScript cheatsheet

出典画像: JS_CheatSheet.jpeg

11 項目

この画像は元々表形式ではないため、「項目 / 要点 / コード」の表に整理しています。

項目要点コード / 例
Promiseの状態pending のPromiseは fulfilled（value）または rejected（error）になり、どちらも settled（outcome）となる。pending → value / error → outcome
Promise.all()Promise配列を、結果の配列を返す1つのPromiseにまとめる。1つでもrejectされると、そのerrorが渡される。Promise.all([value1, value2, value3]) → [value1, value2, value3]
Promise.race()最初にsettledになったPromiseの結果を通す。Promise.race([...]) → 最初の value / error
async / awaitasync関数は常にPromiseを返す。awaitはPromiseのfulfilledを待ち、その値を返す。Promise以外の値もawait可能。awaitはasync関数内でのみ使用できる。async function() { try { let value = await outcome } catch (error) { ... } }
promise.then(onFulfilled, onRejected)fulfilled時はonFulfilled、rejected時はonRejectedを呼ぶ。handlerが値を返せば次のfulfilled値、throwすれば次のerrorになる。onRejected未指定ならerrorは通過する。value.then(value => nextValue) / error.then(..., error => value)
promise.catch(onRejected)onFulfilledを省略したthenと同様。fulfilled値はそのまま通過する。error.catch(onRejected) ⇔ error.then(..., onRejected)
promise.finally(onFinally)outcomeが得られた時に引数なしでonFinallyを呼び、入力Promiseの結果をそのまま通す。outcome.finally(() => ...) → outcome
new Promise()new Promiseに渡した関数は同期的に実行され、resolve(value)またはreject(error)で結果を決める。new Promise((resolve, reject) => { ... resolve(value) ... reject(error) ... })
Promise.resolve() / reject()値からfulfilled / rejected Promiseを作成する。fulfilled Promiseをresolveすると1つに畳み込まれる。Promise.resolve(value) → value / Promise.reject(error) → error
delayの例rejectや返す値が不要なPromiseも作れる。function delay(milliseconds) { return new Promise(resolve => setTimeout(resolve, milliseconds)) }
非同期実行タイミングthen / catch / finally は、すでに結果があるPromiseでも少なくとも次のtickまで実行されない。awaitも結果が既にある場合や非Promise値でも少なくとも次のtickまで待つ。next tick
