# Portfolio Site

Public source repository for selected portfolio pages and browser-side tools.

This repository is intentionally maintained as a clean public history. Private operational history, deployment credentials, server-only configuration, mutable runtime state, and operator-only tooling are not imported here.

## Publication model

Content is added in reviewed stages. Only material explicitly approved for public release is copied into this repository.

The initial publication stage focuses on static and browser-side portfolio surfaces. Runtime-backed or operator-sensitive services are reviewed separately before publication.

## Production boundary

This repository is not the production deployment authority. Changes here do not deploy or mutate the live site.
