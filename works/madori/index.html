ENTRY 008 / CREATIVE TOOL

Floor plan editor / 2D + 3D

間取図
メーカー

部屋や家具を配置し、壁を描き、同じ編集データをそのまま3D空間へ。ブラウザだけで間取りの検討から書き出しまで試せる編集ツールです。

OUTPUT
PNG / Responsive Web

01 / OVERVIEW

図面を描く操作と、
立体で確かめる体験をひとつに。

2Dキャンバス上の部屋・家具・壁を共通の状態として保持し、その状態から3Dシーンを再構成します。編集結果を別ツールへ移すのではなく、同じページの中で視点を切り替えて確認できることを核にしました。

03 / FEATURES

ひとつの状態を、
複数の見え方へ。

01

2D編集

部屋と家具の追加・移動・8方向リサイズ、壁の描画と削除、グリッドスナップに対応。

02

3D確認

2Dで配置した状態からThree.jsのシーンを生成。回転・ズーム・俯瞰切替で空間を確認できます。

03

保存と復元

編集状態とカスタム部屋・家具タイプをJSONへ保存。後から読み込んで作業を再開できます。

04

画像出力

2D図面と3Dビューの双方をPNGとして書き出し、検討結果をそのまま持ち出せます。

VIEWCanvas 2D / Three.js 3D

見た目を二重管理せず、編集状態を単一の情報源として扱います。2Dで変更した位置・大きさ・色は、3Dへ切り替えたときにその場で再構成されます。

05 / HOW TO USE

まずは3手で。

  1. 1
    部屋や家具を追加

    左パネル、スマートフォンでは「＋ 追加」から配置します。

  2. 2
    動かして形を整える

    ドラッグで移動。選択中のハンドルでサイズを変更し、必要なら壁も描きます。

  3. 3
    3Dで空間を確認

    3Dビューへ切り替え、回転・ズーム・俯瞰表示でレイアウトを確かめます。
