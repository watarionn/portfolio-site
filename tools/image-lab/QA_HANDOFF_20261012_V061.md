## v0.6.1 release: pointer ownership
- Defect from source audit: `startStroke` previously accepted a second `pointerdown` while a stroke was active, replacing the draft and its Undo baseline. On touch devices that can silently interleave gestures.
- Fix: a new stroke is accepted only if no pointer is active; secondary non-primary touches are ignored. Existing matching-`pointerId` handling for move/up/cancel remains unchanged.
- No change to original image RGBA, one-owner-per-pixel representation, semantic model, network handling, or effects.

## Physical iPhone Safari acceptance checklist (retained as reusable regression plan)
User accepted v0.6.0 and the later published v0.6.1 on the actual iPhone on 2026-10-12. The following is a reusable regression checklist, **not** an assertion that every individual case has an independently captured test record:
1. Open the production URL from the Home Screen and Safari; confirm the app responds after reload (watch for old PWA cache).
2. Use the built-in sample; switch to Color decomposition, verify layers and original/result previews.
3. Online, try AI Semantic on a photo with a person; verify meaningful hair/face/garment layers; allow model/runtime first load.
4. Select at least two layers and merge; Undo restores both layer list and visual result.
5. Move a selected layer up/down, then Undo. Its pixel ownership remains stable. Reordering does **not** change visual overlap with the current disjoint model.
6. Start boundary brush; Add and Remove to an explicit target, drag a finger along a border, and Undo. Compare against immutable ORIGINAL and exported PNG.
7. For v0.6.1 only: while drawing with one finger, touch briefly with another. The second finger must not replace or commit the first finger's stroke. Undo should revert that single stroke.
8. Test PWA reopen offline after assets are cached. The app shell can load offline; first-time AI model download cannot.
