# Pose Studio v1.5.0

Pose Studioの画面は「3Dポーズ」「ポーズDB」の2つに整理した。ユーザー未使用の2D編集ページはUIから退役したが、互換性が必要な既存2Dロジックとデータは削除していない。

## 普段の使い方

1. 「3Dポーズ」でグレーマネキンの関節やカメラを操作する。
2. 「3D出力」から現在視点PNG、4方向シート、OpenPose画像・JSON、3DポーズJSONを保存する。
3. 「DBに登録」でタイトルとタグを付けて保存する。
4. 「ポーズDB」の「3Dへ読み込む」から再編集する。

3Dはポーズプリセット、関節ドラッグ・簡易IK、XYZ角度スライダー、視点回転、ズーム、Undo/Redo、A↔Bアニメーション、GIF・動画出力を維持する。グレーマネキンの人物性を持たない外観も維持する。

## 旧2Dデータの扱い

- 「2Dポーズ」タブと「現在視点を2Dへ送る」ボタンは画面から除外。
- 古い2D専用ポーズは削除せず、ポーズDBに引き続き表示する。
- ポーズDB内の2D投影データや古い2D専用データは「2DデータJSON保存」で個別に書き出せる。
- DBのJSON入出力スキーマv1は維持する。
- 3D保存時には現在視点の2D投影を含むデータを従来どおり記録する。
- 3DのOpenPose画像・JSON出力は引き続き利用可能で、2D編集画面は不要。
- 旧2D編集DOMおよび `pose2d.js` は互換処理（3D保存時の2D状態、DBプレビュー）のため非公開のまま保持。削除やデータ変換はしない。

## 保存場所

ブラウザ内ポーズDBは作業用。長期保存には `pose-db.json` を書き出し、採用済みのGitHub / Google Drive正本へ保存する。

## 実装構成

- `pose3d.js`: 3D関節編集、投影、OpenPose出力、アニメーション
- `pose2d.js`: 旧2Dデータ互換、2Dプレビューと投影保存のため内部維持
- `store.js`: DB v1スキーマ（変更なし）
- `app.js`: 3D・DB二画面ナビゲーションと旧2Dデータ書き出し
- `pwa.js`: 3D操作パネルのモバイル対応
- `service-worker.js`: v1.5.0キャッシュ
