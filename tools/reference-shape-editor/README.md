# Reference Shape Editor 1.2

Minimalizerの手本画像を作るための、ブラウザ内だけで動く手動の多角形エディター。画像の自動生成や描き足しはしません。

## 開き方

**最も簡単な方法**: 公開サイトの `/reference-shape-editor/` を開く。オフライン単体版は `watarionn/Minimalizer` の `web/static/reference-shape-editor.html` にあり、ダウンロードしてChrome、EdgeまたはSafariで開けます。CSS/JSをHTMLに内蔵し、サーバは不要です。

**ソース版**: `index.html`、`styles.css`、`app.js` を同じディレクトリに置き、`index.html` を開く。Webサーバが必要な環境では `python -m http.server 8000` で同じ内容を確認できます。

## 作業手順

1. 「画像を開く」で元画像（PNG/JPEG/WebP/GIF）を読み込みます。画像は自動的に35%の不透明度で下敷きに表示されます。縦長画像は最初から横幅に合わせ、編集領域は画面全体を使えます。スライダーで0〜100%に変更できます。
2. 「図形化」モードでキャンバスを順番にクリックし、3個以上の頂点を指定します。**既存の頂点に12px以内に近づけると、同じ頂点を参照して再利用します**（スナップ範囲は調整可能）。
3. 「図形化」ボタンまたは Enter で多角形を閉じて塗りつぶします。自己交差または点の重複がある新規図形は拒否されます。
4. 左の「選択」「頂点」「移動」に切り替え、形・色・前後関係を調整します。右のレイヤー一覧の**≡ハンドルをドラッグ**して重なり順を変更できます。**共有された頂点を動かすと、隣接図形が同時に追従します**。
5. 「頂点」モードで図形を選び、点をドラッグできます。辺の上をダブルクリックするとその辺に頂点を追加します。選択中の点は Delete で削除できます（図形の頂点数は最低3点）。
6. 3分類から重複を除いた**パレット**で色を選べます。色をタップして選択後、HEX・カラーピッカーから色を更新、または削除できます。「＋追加」で任意色を登録できます。元のCharacteristic/Featured/Representativeの候補も残ります。
7. 複数レイヤーにチェックを入れて**「選択レイヤーを統合」**で1つの複合レイヤーにできます。統合後も個別の多角形、色、共有頂点はそのまま保持し、**「分割」**で戻せます。単一の幾何学的な和集合ポリゴンへ変形する機能ではありません。
8. 「下敷き 01」「頂点スナップ 02」は初期状態で閉じたアコーディオンです。不要な「縦位置」スライダーは削除し、既存のパン・ホイール・ズーム機能は維持しています。
9. 途中保存は「JSON保存」。次回は「JSONを開く」で図形・共有頂点・複合レイヤー・編集したパレット・下敷き画像を復元できます。完成画像はSVGまたはPNGで書き出します。

### ColorStripについて

オフライン単体版は、元画像から色候補を**ブラウザ内で独自計算**します。`Characteristic / Featured / Representative` は ColorStrip の考え方を参考にした近似値で、Minimalizer Python/JSの公式ColorStrip結果と**一致することは保証しません**。

Minimalizer側で確定したColorStripパレットを使いたいときは、「色を読込」でJSONを指定してください。以下の形式に対応しています。

```json
{"metadata":{"colors":[{"rgb":[34,56,78]},{"rgb":[210,143,97]}]}}
```

ほかに `colors: ["#123456", ...]`、`characteristic`、`featured`、`representative` を持つJSONも読み込めます。ブラウザ推定であるかインポート済みであるかを画面に表示します。

## 互換性・回帰テスト

- JSONスキーマ名 `reference-shape-editor/v1` を維持。レイヤー統合は追加項目 `layerGroups` で記録し、既存の `shapes` と `vertices` を破壊しません。旧JSONは `layerGroups` なしでも読めます。
- `palette.unified` は既存の3分類と独立した、重複のないユーザー編集用パレットです。削除しても既存図形の色や元の分類候補は変化しません。
- SVG/PNGは既存の全図形を順序通りに出力します。下敷き画像は出力に入りません。
- `node tools/test_reference_shape_editor_core.js` で追加機能のコア回帰テスト。実際のブラウザのタッチ／ドラッグ操作は別途実機確認が必要です。

## 書き出しと安全性

- **SVG/PNG**: 手描き多角形だけを出力し、下敷き元画像を埋め込みません。出力は透明背景。SVGでは領域ごとの塗り色と図形名を維持します。
- **JSON**: 編集再開のため、下敷き画像をbase64で**含みます**。このJSONは非公開資料として扱ってください。図形座標も元画像基準です。
- 画像解析はブラウザ内で実行。外部モデルや通信APIは利用しません。サードパーティ依存なし。
- 入力画像最大24MB、読み込む画像の縦横最大12,000px。PNG書き出し最大48メガピクセル。
- 操作は変更履歴として直近100件まで取り消し可能。ブラウザを閉じた際の自動保存はありません。こまめにJSON保存してください。
- 公式C04 Goldenの人間の承認を代行・偽造しません。出来上がった見本も自動的に正解認証されません。

## ショートカット

`P`:図形化、`V`:選択、`E`:頂点編集、`M`:図形移動、`H`:パン、`I`:元画像から色採取、`Space`（押している間）:パン、`Enter`:図形化、`Esc`:頂点列取り消し、`Backspace`:点をひとつ戻す、`Ctrl/⌘+Z`:戻す、`Ctrl/⌘+Shift+Z`:進む、`Delete`:選択図形/頂点削除。ホイール:上下スクロール、Shift+ホイール:左右、Ctrl/⌘+ホイール:カーソル中心ズーム、+/-:ズーム、上部「全体表示」「幅に合わせる」、縦位置スライダー。スマホでは右パネルの開閉ボタンが利用できます。

## 開発配置

Minimalizer 本体の正式変換パイプラインとは独立。既存 C02/C03/C04 の Golden 判定・公開環境・ローカルWorkerの設定を変更せず使用します。

## Webサイトへの設置

公開サイトでは `/reference-shape-editor/` に設置。図形・画像はブラウザ内のみで扱い、外部へアップロードしません。ページは静的なHTML/CSS/JSのみ。JSON保存には元画像が含まれるため、公開リポジトリへ手作業プロジェクトを置かないでください。
