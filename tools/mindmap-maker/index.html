MindMap Maker v1.0

思考を、軽く、自由につなぐ。

追加・接続・整理・検索まで、ブラウザだけで完結する軽量マインドマップエディタです。データはこの端末に保存されます。

1. 追加空白をクリックしてノードを置く
2. 編集ノードを選んで文字や色を変更
3. 接続2つのノードを順番に選んでつなぐ
4. 整理検索・複数選択・自動整列で整える
使い方

基本操作

追加：空白をクリック / タップしてノードを追加。

編集：ノードを選択。ダブルクリックで文字を編集。

接続：接続モードで、始点と終点のノードを順番に選択。

複数：ドラッグ範囲選択後、グループ化や一括削除。

便利な機能

検索でノードへ瞬時に移動。自動整列は接続関係をもとに配置します。右下のミニマップから大きなマップ内を移動できます。

ショートカット

Ctrl / ⌘ + Z元に戻す Ctrl / ⌘ + Shift + Zやり直す Ctrl / ⌘ + S保存 Ctrl / ⌘ + OJSONを開く Ctrl / ⌘ + F検索 Ctrl / ⌘ + D選択ノードを複製 F全体表示 L自動整列 ?このヘルプ Esc閉じる / 解除

保存について

自動保存はブラウザの localStorage を使用します。外部サーバーへの送信処理はありません。端末をまたぐ場合はJSONで書き出してください。
