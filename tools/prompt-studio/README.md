# Prompt Studio

Prompt Studioは、描きたい画像の内容を項目ごとに組み立て、FLUX / SDXL / GPT Imageなどに合った書き方へ変換し、気に入ったプロンプトを蓄積できる制作ツール。

## 基本の使い方

1. 「出力先モデル」で使うモデルとプロンプト書式を選ぶ。
2. 「画像の内容」に主役、動作、背景、光、カメラなどを入力する。
3. 右側の「生成プロンプト」をコピーして画像生成ツールで使う。
4. 良い組み合わせができたら「DBに登録」で保存する。

画面内の丸い `i` ボタンから、その場所の説明を確認できる。

## 組み立てルール

プロンプトDBのパーツ辞書を使って、「画像の内容」へ値を自動入力できる。

選び方は次の3種類。

- 手動: 固定値を入れる
- 重み付きランダム: パーツごとの重みに応じて抽選する
- 順番: 登録順に1つずつ使う

ルールの並びはドラッグまたは上下ボタンで変更できる。
よく使う組み合わせは「組み立てレシピ」として保存・再読込できる。

## プロンプトDB

### 保存済みプロンプト

気に入ったプロンプトを、タイトル・タグ・画像内容・モデル名と一緒に保存する。

### パーツ辞書

人物、服装、動作、ポーズ、場所、光、カメラなど、繰り返し使う要素を登録する。

各パーツは次の情報を持てる。

- プロンプト用の内容
- 日本語ラベル
- タグ
- 抽選の重み

### 組み立てレシピ

「どの項目へ、どのパーツ辞書から、どの選び方で入れるか」というルール一式を保存する。

## モデル別の出力

- FLUX: 自然文
- GPT Image: 指示文
- SDXL: 自然文またはタグ形式
- 共通: 短いタグ形式

FLUX / GPT Imageでは、ネガティブプロンプト欄を使用しない。

## 保存について

ブラウザ内のデータは作業用。
`プロンプトDBを書き出す`で `prompt-db.json` を保存できる。
長期保存する正本はGitHubまたはGoogle Driveへ置く。

## 内部構成

- `engine.js`: 内容データからモデル別プロンプトへの変換、パーツ抽選
- `store.js`: プロンプトDBの保存・読込
- `app.js`: 基本UI、保存済みプロンプト、Import / Export、ヘルプ
- `slots.js`: 組み立てルールとレシピ
- `db-editor.js`: パーツ辞書とレシピの編集UI
