# AI Creation Workbench

## Short copy

Prompt・Pose・Model・Assetを行き来できる、ローカルファースト制作支援ワークベンチ。

## Description

AI Creation Workbenchは、個別に作っていた制作補助ツールを1つのWebアプリへ統合した制作支援環境です。PromptDB互換の候補生成、ポーズ編集、Civitaiモデル情報の整理、PNG/JSON素材監査を5つのワークスペースに分け、制作メモとお気に入りをNotebookで横断管理できます。

元ツールの役割を残したまま、PromptDBフォルダ読込、Offline JSONフォールバック、非破壊Asset collect、初回ガイド、サンプルWorkspace、アクセシビリティと公開向けメタデータを追加してv1.0へ仕上げています。

## Highlights

- Prompt Lab: seed再現、PromptDB互換、TXT/CSV/JSON出力
- Pose Studio: 関節ドラッグ、プリセット、参照画像、PNG/SVG/JSON保存
- Model Inspector: Civitai URL解析、API / Offline JSON、CSV/JSON出力
- Asset Organizer: PNG/JSONペア監査、孤立検出、manifest、非破壊collect
- Notebook: 制作メモ、Prompt/Modelお気に入り、Workspace JSON
- Vanilla JavaScript主体、ビルド工程なし
