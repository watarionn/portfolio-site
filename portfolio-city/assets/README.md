# Portfolio City assets

Phase 3.2では、Phase 3.1の共通仮設アイコンを廃止し、14作品それぞれをHTML/CSSだけの異なる線画シルエットとして表現しています。画像生成物に頼らず、都市全体の編集的な紙面感と馴染む手作業の造形を優先します。

- `buildings/`: 各作品の建物外観
- `landmarks/`: 地区の目印
- `characters/`: 将来の人物・案内役
- `environment/`: 道路、水辺、植栽、背景など

後続Phaseで補助的な画像やSVGを追加しても、`data/projects.json` と `data/districts.json` を都市データの基準として扱います。
