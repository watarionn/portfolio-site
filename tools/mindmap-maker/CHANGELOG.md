# Changelog

## 1.0.0 - 2026-09-17

### Added
- JSON import and full document restore
- Browser autosave and save-state indicator
- Map title
- Node full-text search
- Minimap navigation
- Connection-aware auto layout
- Full-map PNG / JPG / SVG export
- Cloud node selector
- First-run onboarding
- Built-in sample map
- Help / shortcut reference
- Web App Manifest, favicon and OGP metadata
- Accessibility labels, focus indicators and reduced-motion support
- Responsive restore across substantially different viewport widths

### Fixed
- Export range no longer depends on the current viewport
- Load/reset history handling
- Cloud outline generation at compact sizes
- Secondary text contrast
- Desktop-saved viewport being unsuitable when restored on mobile
