# Phase 3.9 CP1 Skeleton Harness

Development-only interaction prototype for Portfolio City.

## Scope

CP1 validates only the normalized H2 world plane and four current district hit regions.

Included:
- abstract mainland / water / highland / offshore shapes,
- Archive, Observatory, Workshop, and Waterside anchors,
- F-A / F-B / F-C frontier markers,
- noninteractive cloud/frontier scenery,
- keyboard-focusable district buttons,
- prototype debug overlay,
- responsive first-pass framing.

Not included yet:
- map pan,
- camera persistence,
- District View,
- project buildings,
- Building Preview,
- production routing,
- final illustrated geography.

## Run

Open `index.html` directly in a browser or serve this directory with any local static server.

This directory is isolated from the production runtime.
